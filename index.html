Personal System

PROJECT 01 / CONTENT GROWTH

Scientific Research Content Growth

科研教育内容增长体系

角色内容增长运营 / 用户洞察 / 内容策划

AI内容生产

项目成果

  • 负责科研与国际组织产品的蓝V及KOS账号矩阵

PROJECT 04 / AI TOOL WORKFLOW

Agent Workflow Design System

AI工具方法论与插件化工作流案例

SourceSuperpowers open-source skill framework

Role产品叙事 / 信息架构 / workflow转译

STRATEGY

把一个偏工程的agent技能仓库，转译成可被作品集访客理解的AI工具案例：它展示的不是页面运行效果，而是规划、测试、调试、审查与交付如何被组织成稳定流程。

01Brainstorm从模糊想法进入需求澄清
02Plan把设计拆成可执行任务
03Build用TDD与子任务推进实现
04Review通过代码审查和验证收尾

为什么放进作品集

原仓库不适合作为可运行前端项目展示，但它非常适合转译成“AI工具/工作流设计”案例。它能证明我理解AI产品不只是生成内容，更重要的是如何设计可靠的人机协作流程。

我的转译方式

我从README、插件清单与skills目录中提取产品叙事，将“技能包、hook、agent workflow、TDD、debugging、code review”等工程概念，重新组织为面向非工程访客也能理解的案例结构。

展示价值

  • 体现AI工具信息架构与复杂概念转译能力
  • 补足作品集中“工作流设计”维度
  • 连接AI内容增长、自动化协作与产品叙事
  • 将开源项目从工程素材转化为可读案例
skill brainstorming intent to spec skill writing-plans spec to tasks skill tdd red green refactor skill code-review verify delivery

07 / PERSONAL STATEMENT

我对“标准答案”兴趣不大。

相比于遵循既定路径，我更喜欢观察系统如何运转：用户为什么点击，内容为什么被相信，技术如何改变表达，商业价值又如何在其中生成。

抽刀断水水更流。

我无法停止信息流动，但可以研究它如何流向人、信任与行动。
